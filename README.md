# twitter-media-dl
This python script uses the json file generated by https://github.com/prinsss/twitter-web-exporter to download all media files to the set directory.

It takes the json file with the "Include all metadata" option enabled, and downloads all media at once. It also sets the file modified date to the date of the tweet, useful to have the bookmarks ordered by date in a picture gallery such as immich.

I have not bothered with a way to configure this properly, but the json file path and save directory can be modified in the script if necessary.

    json_file =  "bookmarked_tweets.json"  # Path to your JSON file
    save_directory =  "downloaded_media"  # Directory where downloaded media will be saved

Note: I vibecoded this script several years ago for my personal use. I am putting it in there just in case it can be useful for anyone else.
